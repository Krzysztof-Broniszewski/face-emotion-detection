# Face Emotion Detection

**EN:**  
A real-time facial emotion recognition project using OpenCV, MediaPipe (468-point Face Mesh), and Gradio UI.  
The goal is to create a lightweight interface for analyzing facial expressions and emotions, later extended with custom PyTorch models and affective computing for lie detection.

**PL:**  
Projekt rozpoznawania emocji twarzy w czasie rzeczywistym z obrazu kamery (OpenCV + MediaPipe + Gradio).  
Celem jest stworzenie lekkiego interfejsu do analizy mimiki i emocji, który w przyszłości zostanie rozszerzony o własne modele PyTorch i analizę ekspresji twarzy w kontekście wykrywania kłamstw.  

---

### 🔧 Features (planned)
- Live camera preview (OpenCV + Gradio)
- Face Mesh 468 landmarks (MediaPipe)
- Emotion prediction using FER2013 dataset
- Model fine-tuning in PyTorch
- Potential extensions: attention tracking, lie detection, affective behavior modeling

---

### 🧠 Technologies
`Python` · `OpenCV` · `MediaPipe` · `Gradio` · `PyTorch` · `FER2013`
